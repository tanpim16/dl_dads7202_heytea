**Task:** Build an image classifier with CNN on a self-collected dataset  
**Topic:** Thai tea drink classification (5 classes)

---

## Project Summary

We classify 5 types of Thai tea drinks that are **not** in ImageNet's 1,000 classes:

| Class | Description |
|---|---|
| `cha_dam_yen` | Iced black tea |
| `cha_khiao_nom` | Green milk tea |
| `cha_nom_khai_muk` | Bubble milk tea |
| `cha_phonlamai` | Fruit tea |
| `cha_thai` | Thai iced tea (orange) |

Images were collected via **web scraping** (Bing + Baidu, 2 rounds) and curated using CLIP-score filtering + manual review sheets.

## Dataset

| Split | Count | Note |
|---|---|---|
| Train | ~614 (70%) | WeightedRandomSampler + augmentation |
| Val | ~88 (10%) | Used for early stopping |
| Test | ~176 (20%) | **Fixed, never seen during training** |

**Class imbalance** (current clean set):

| Class | Count |
|---|---|
| cha_nom_khai_muk | 221 |
| cha_thai | 220 |
| cha_khiao_nom | 202 |
| cha_phonlamai | 153 |
| **cha_dam_yen** | **82** ← needs more images |

**Imbalance strategy:**
1. `WeightedRandomSampler` in DataLoader (oversamples minority during training)
2. `class_weight` in `CrossEntropyLoss` (penalizes errors on minority class more)

---

## Model Architectures

| # | Architecture | Params | Role |
|---|---|---|---|
| 1 | VGG-16 | ~138M | Baseline — simple, large |
| 2 | ResNet-50 | ~25M | Skip connections, strong benchmark |
| 3 | EfficientNet-B3 | ~12M | Best accuracy/efficiency for fine-grained |
| 4 | MobileNet-V3-Large | ~5.5M | Lightweight comparison point |

All use **two-stage fine-tuning**:
- Stage 1: Freeze backbone → train classifier head only
- Stage 2: Unfreeze last few backbone layers → lower LR fine-tune

## Training Code (`training/`)

```
training/
  config.py        — paths, class names, seeds, BEST_HPARAMS (edit after sweep)
  dataset.py       — TeaDataset, stratified splits, WeightedRandomSampler
  models.py        — build_model(), freeze/unfreeze helpers, GradCAM target layers
  trainer.py       — two-stage training loop with W&B logging
  evaluate.py      — metrics, mean±SD, Welch's t-test, confusion matrix plots
  gradcam.py       — GradCAM implementation + correct/wrong visualization
  utils.py         — set_seed(), get_device()
  run_sweep.py     — W&B Bayesian sweep (run first)
  run_final.py     — 5-seed final runs + all plots/CSVs (run after sweep)
  requirements.txt
```

**How to run:**
```bash
cd training
pip install -r requirements.txt

# Step 1: hyperparameter search (~60 W&B runs)
python run_sweep.py

# Step 2: fill in BEST_HPARAMS in config.py from sweep results

# Step 3: final 5-seed evaluation
python run_final.py
```

**Outputs** (saved to `results/`):
- `summary.csv` — mean±SD for all metrics per architecture
- `ttest.csv` — pairwise Welch's t-test results
- `cm_{arch}.png` — confusion matrices
- `gradcam_{arch}.png` — GradCAM correct vs. misclassified
- `comparison_f1.png` / `comparison_acc.png` — bar charts
- `per_class_f1.png` — per-class F1 heatmap

## Common Mistakes to Avoid (from example feedback)

| Issue | Fix |
|---|---|
| Not stating which set results are from | Always write "test set" explicitly |
| Not specifying which seed for learning curves | Pick best or median seed, state it |
| Not specifying F1 averaging method | Use **weighted**, state it in slides |
| Bar chart for mean±SD | Prefer **strip/dot plot** (teacher suggestion) |
| Only reporting p-value | Add **effect size** for bonus points |
| GradCAM only on correct predictions | Show **both correct AND wrong** cases |
